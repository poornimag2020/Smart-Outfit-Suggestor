# 👕 Outfit Suggestor

An interactive web application built with **Python and Streamlit** that suggests a suitable outfit based on the **weather** and **occasion** selected by the user.

## 📌 Project Overview

The **Outfit Suggestor** is a simple rule-based application created as part of my Python learning journey.

Users can select the weather condition and occasion, and the application provides a suitable outfit suggestion.

## ✨ Features

- 🌤️ Select the weather:
  - Sunny
  - Rainy
  - Cold

- 🎉 Select the occasion:
  - Casual
  - Formal
  - Party

- 👕 Get an outfit recommendation based on the selected options
- 🖥️ Interactive Streamlit interface
- 🎨 Clean and user-friendly design

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Conditional Statements**

## ⚙️ How It Works

The application uses conditional statements to match the selected **weather** and **occasion** with a suitable outfit.

### Example

**Weather:** Rainy  
**Occasion:** Casual  

**Suggested Outfit:**  
👕 T-shirt + 👖 Jeans + ☂️ Umbrella

Another example:

**Weather:** Cold  
**Occasion:** Formal  

**Suggested Outfit:**  
👔 Formal Shirt + 👖 Trousers + 🧥 Coat
